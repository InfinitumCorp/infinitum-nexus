## Design references (no code included)

### PhishCatch

- Idea used: warn when a password protected for one site is typed on another,
  by comparing salted hashes in the browser (`lib/password-guard.js`).
- Source: https://github.com/redcanaryco/phishcatch, Apache License 2.0.
- No PhishCatch code, text or assets are included; VEIL's implementation was
  written independently.

## Infinitum Corporation's own work

- **Blocklist** (`lib/blocklist.js`, generated into the Android app's
  `Blocklist.java`): curated by Infinitum Corporation. It is not copied from
  any third-party filter list. Common public lists are GPL, CC BY-SA or
  non-commercial, so none is included.
- **Download check** (`lib/downloads.js`) and **personal-data form check**
  (`lib/content-pii.js`): pattern rules written for VEIL.

## Optional geo routing data (not stored in git)

VEIL can add v2fly geosite categories to the curated blocklist, and can bypass
extra site names on the CID-entitled exit. Both are off until the geo routing
switch is turned on. `.onion` names are never bypassed. The `.dat` files are
downloaded by `scripts/fetch-geo-dat.mjs` into `data/geo/` and checked against
the publisher's `.sha256sum` assets. They are not copied into this repository.

## Considered and not used

- **Magika** (Google, Apache-2.0) for file-type detection, and **privacy-filter**
  (OpenAI) for personal-data detection. Both need a model runtime that is too
  large for a browser extension, and the browser's downloads API does not
  expose file contents. VEIL uses the pattern checks above instead.
